# Version 2025.7.12.0

This article describes the changes contained in the update.

## New features

* The **Monthly report** is now available.

## Fixed bugs

* Fixed a bug that caused that editing an transaction may fail silently.
* Fixed a bug that caused that a wrong localized value was used in transaction amount field.
* Fixed a bug that caused the **current month** filter in the account transactions view may not work properly.
* The **duplicate transaction** command now works correctly.
* The **Customize QAT commands** menu now works correctly in the ribbon.

## Changed behaviors

* Linked transactions are better handled now. Finko asks if you want to edit the linked transactions. 
* Changed internal things to make view flicker less when navigating.
